## ✨ Öne Çıkan Özellikler

- 🏬 **Blok ve Daire Yönetimi:** Daire sakini bilgileri, mülk sahibi/kiracı durumu.
- 💵 **Aidat ve Gelir-Gider Takibi:** Daire bazlı borçlandırma, tahsilat ve gecikme takibi.
- 📊 **Finansal Raporlama:** Kasa durumu, aylık gelir-gider grafik snapshot'ları.
- 🔐 **Yetkilendirme ve Güvenlik:** Yönetici ve kullanıcı rolleri ile güvenli oturum yönetimi.
- 📱 **Mobil Uyumlu Arayüz:** Responsive tasarım ile tüm cihazlardan erişim.

---

## 🛠️ Teknolojiler ve Mimariler

- **Backend:** Native PHP (Procedural / MVC Mimarisi)
- **Database:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Tools:** Laragon / XAMPP, Git
